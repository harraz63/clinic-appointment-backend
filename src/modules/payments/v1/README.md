# Payments foundation

Independent payment method and payment record models are prepared, with a cash method created by migration. Amounts/currencies are immutable booking-derived service inputs. Cash collection, payment totals, refunds and future manual verification are unimplemented. No gateway or proof-upload integration exists.

No HTTP routes are mounted for this module. See [the clinic foundation](../../../../CLINIC_FOUNDATION.md) for relationships, access rules, future routes, verification and roadmap.
